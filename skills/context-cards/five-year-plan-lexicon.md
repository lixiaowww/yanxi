# Context card: Five-year plan lexicon (background)

| Term | Plain English gloss |
|------|---------------------|
| 五年规划 / 规划纲要 | Multi-year Party–state planning document; sets priority vocabulary more than precise micro targets |
| 十四五 / 十五五 | 14th / 15th Five-Year Plan period labels in public discourse |
| 远景目标 / 二〇三五 | Longer-horizon (e.g. 2035) aspiration language — high direction, low instrument detail |

**Discipline:** Plan vocabulary ≠ enacted statute. Prefer watchpoints for subsequent 细则/通知.
