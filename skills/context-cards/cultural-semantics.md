# Context card: Cultural / discourse semantics (background)

These terms shape how audiences read a text. Explain tone; do not psychologize unnamed individuals.

| Term / theme | Analyst note |
|--------------|--------------|
| 稳定 / 和谐 | Stability and harmony frames often prioritize order and predictability in public messaging |
| 正能量 / 主旋律 | Discourse cues favoring affirming mainstream narratives |
| 舆论 | Public opinion / media climate — distinguish "reported sentiment" vs proven majority view |
| 内卷 / 躺平 | Popular sociological slang about competition fatigue; informal register |
| 家国情怀 | Patriotic-familial duty rhetoric; common in education/culture texts |

**Discipline:** Semantic gloss helps English readers; it is not a claim about secret intent.
