# Context card: 党八股剥离 → 干货清单

公开党政话语里大量是**可预期的仪式语**（党八股）。民用阅读法不是「揭秘洗脑」，而是：

1. **先划套话**：两个维护、深入贯彻、凝心聚力、强调/坚持/推动…  
2. **再列干货**：只保留可在后续公开源复核的线索  
3. **干货空则降置信度**，outlook 只写 continuity / wait-for-细则

## 干货九类（与 `substance_cut` 同步）

| 种类 | 例子 |
|------|------|
| 数字/比例 | 5%、8000亿元、万吨 |
| 时间表 | 2026年底、十四五、年内 |
| 具名工具 | 通知/办法/细则/目录/清单 |
| 责任主体 | 国办、工信部、有关部门要… |
| 试点/范围 | 试点、分批、全国推开 |
| 红线/禁止 | 不得、严禁、守住底线 |
| 资金/资源 | 专项资金、专项债、贴息 |
| 具名行业/地域 | 芯片、地方债、长三角 |
| 缓急/转向 | 首次、更加突出、暂缓、加力 |

## Discipline

- 套话命中 ≠ 无信息；可能是**议程排序/气氛**，但不是操作细节。  
- 禁止把「宣传语气」写成秘密意图或「洗脑成功」。  
- `substance_cut.band=thin|mixed|dense` 只调节阅读，不替代人审。
